# EconoCausal

Dynamic Pricing via Double Machine Learning.

## Week 1 Objectives
- Generate and clean customer campaign data.
- Perform exploratory data analysis.
- Define a causal DAG using DoWhy.
- Build a React dashboard for CSV uploads.

## Technology Stack
- Python, Pandas, NumPy
- DoWhy, scikit-learn
- React, Vite, JavaScript

## Project Status
Week 1: Foundation and initial dashboard.

## Disclaimer
The initial dataset contains simulated customer data.
Results are for educational demonstration and are not
evidence of real-world causal effects.
